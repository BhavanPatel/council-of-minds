# Documentation

Council of Minds is a **council of Minds** — markdown files, each a distinct perspective, in
**two kinds**: **Advisors** (reason to a recommendation) and **Researchers** (retrieve a sourced
answer). They work solo or chained, and an installation CLI copies them into whatever AI agent you
use. Start with concepts, then dive into whichever kind of Mind you need.

## Start here

- [concepts.md](concepts.md) — what a Mind is, the two kinds, solo vs chained, and the install model.

## The two kinds of Mind

- [advisors.md](advisors.md) — the **Advisor** Minds: the full roster, the profiles that group them,
  how they reason and vote, and how to add your own.
- [researchers.md](researchers.md) — the **Researcher** Minds: the full roster, the profiles that
  group them, how they retrieve evidence, and what a sourced answer looks like.
