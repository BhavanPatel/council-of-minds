# Examples

Worked council sessions live in the [`docs/examples/`](examples/) folder, split by kind of Mind.
This page is an index — pick the example set that matches what you're asking.

## Advisors — "what should I do?"

- [**Decision examples**](examples/decision.md) — the full verdict output format, every advisor
  profile, the three modes (Full / Quick / Duo), budget tiers, and feature examples (fact-checker,
  early termination, analytics).

## Researchers — "what is true?"

- [**Research examples**](examples/research.md) — one worked example per research profile
  (landscape-scan, claim-verification, literature-review, technical-due-diligence, market-research,
  competitive-intel, regulatory-scan, provenance-audit, incident-forensics, trend-forecast,
  quantitative-scan, vendor-evaluation, academic-survey, red-team-research, feasibility-study),
  each with a Charter, panel, and abbreviated Research Verdict.

## Chained — "what should I do, given the current landscape?"

- [**Chained example**](examples/chained.md) — researchers run first, an advisor panel then
  deliberates over the sourced evidence, with dissent preserved at both layers.

See the [examples index](examples/README.md) for the full list.
